A knowledge graph is the corpus read as nodes and edges: every note is a node of its
declared type, and every line of a `# Topology` section is an edge with a label from
the closed set.

A wikilink inside a code span is text, not an edge: `[[concepts/format]]` and the
version `v1` are written here on purpose, and the exporter must leave both alone.
